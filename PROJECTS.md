## Reading this showcase

Start with a project brief, inspect the linked source modules, then use the project's own setup and test commands. Demo animations and synthetic dashboards illustrate behavior; they are distinct from measurements on physical hardware.

The profile focuses on inspectable engineering work. Test results and build state belong to the linked workflow runs and test suites rather than hardcoded achievement badges.
